# My Task Manager

A simple, responsive to-do list for keeping track of everyday tasks. The app is built with plain HTML, CSS, and JavaScript, and saves tasks in the browser with LocalStorage.

## Features

- Add, edit, delete, and complete tasks
- Filter tasks by **All**, **Active**, or **Completed**
- See how many tasks remain
- Keep tasks between visits with LocalStorage
- Responsive layout for desktop and mobile

## Run locally

Open [`index.html`](./.azure/index.html) in a modern web browser. No build tools or dependencies are required.

## Data storage

Tasks are stored locally in your browser. They are not uploaded to a server and are available only in the same browser profile.
